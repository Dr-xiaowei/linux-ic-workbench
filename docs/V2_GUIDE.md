# 0.4.0-rc1 使用说明

这是按 2026-09-25 最新页面分工调整的第一版候选，正式 Linux 和网页 Demo 共用界面。Demo 不提供独立安装包。VS 已由用户确认指 VCS。

## 项目与文件

“添加项目”登记主目录和其他目录的绝对路径，不移动原件。备注、说明和标签保存在工作台数据目录。打开项目后可逐层浏览，每个目录/文件都能添加备注和说明；目录列表直接显示标注。

检索支持文件名、文件备注和文本内容；默认当前项目，可勾选全部项目。受当前 Linux 用户权限限制，不提升权限，不跟随符号链接，不读设备/FIFO，不检索 `.git` 内部。每页最多 100 个匹配、20,000 个文件、32 MiB 内容或 15 秒，点击“继续搜索”会继续，包括大文件中尚未读取的内容。二进制和权限不足项计入跳过统计。每个文件返回首个匹配及行号。扫描期间文件变更会要求重启该检索，结果不是文件系统快照。

项目页面仅管理目录与文件。原有结果、任务和优化数据仍保留在数据目录/API 中；EDA 调用与任务状态在独立“EDA 控制”页面查看。

## AI Agent

在设置中配置完整 Chat Completions URL、模型标识、密钥环境变量名，并启用工具调用。密钥在启动工作台前通过环境变量提供；不写入网页。普通问答不要求项目。仅 AI 对话提供“通用问答 / 项目 / 文件夹”操作范围。文件夹填写工作台所在服务器上的绝对路径，需当前用户可读；切换范围会新建会话，已存会话恢复自己的范围。文件夹浏览/检索使用该目录为根，不必先登记项目；路径越界和符号链接逃逸会拒绝。此选择是操作上下文，不是操作系统权限沙箱；外部执行工具仍需明确批准。

Agent 使用与 GUI 相同的项目、文件检索、报告分析、软件、插件、监测、Code、计算器、MCP、设置、仿真和优化接口。对话显示实际执行阶段与工具回执。勾选“允许本轮修改”才开放写操作；运行软件/插件、关闭任务、保存代码、加载环境配置等展示具体参数并等待批准。取消只停止该 Agent 的后续调用；已提交的独立仿真或软件作业需在任务/执行记录中另行取消。

每次最多 12 轮模型工具交互，每轮最多 8 个调用，整轮 10 分钟，最多 4 个并行会话。模型是否正确规划仍需要接入公司 GLM 后验收。可通过配置的插件扩展工具能力；没有接入互联网搜索服务，不能将通用回答当成联网查询结果。

Demo 使用明确标记的固定规则路由，能实际演示目录浏览、关键词搜索和模拟监测；自由问答、任意需求代码生成及真实 EDA 执行不会被伪装为已完成。

## 软件与环境

一个软件配置名称、统一启动语句、Shell、默认版本。每个版本单独登记环境脚本和工具 PATH。支持 `/bin/sh`、`/bin/bash`、`/bin/csh`、`/bin/tcsh`，只加载子进程，不改 `.cshrc`。版本切换作用于下一次启动，已启动的软件保持原环境。

启动语句是用户信任的 shell 命令，具有当前用户权限。执行记录保存排队、运行、结束及输出，允许取消。图形化 EDA 需要公司已有 DISPLAY/X11/远程桌面与许可证；该网页不内嵌远程桌面。

## 插件单独安装与批量安装

插件是显式命令清单，不是浏览器远程代码。单独安装可填写表单；批量导入接受 JSON 的 `plugins` 数组。导入不执行命令，单独新增默认禁用；脚本或批量清单可显式设置 `enabled`。审阅来源和命令后启用。

```json
{"plugins":[{"id":"report-helper","name":"Report helper","version":"1.0.0","description":"List project files","command":{"executable":"/bin/ls","args":["-la","{project}"]},"enabled":false,"timeoutSeconds":30}]}
```

可将 `executable` 设为 Python/Shell 等解释器，`args` 指定自己的脚本；都是目标 Linux 上的路径。插件页直接运行使用设置中的默认工作目录。只有通过带项目范围的 Agent 调用，`{project}` 才使用所选项目目录。软件页面直接启动同样使用默认工作目录，不受其他页面的选择影响。超时范围 1–3600 秒，最多 8 个待执行/运行的扩展作业。执行受全局工作并发限制。插件不是安全沙箱，不自动下载安装依赖，不向外部服务发送数据。

源码目录使用：

```sh
export ICW_TOKEN='启动网址中 token= 后的值'
python scripts/install_plugins.py --url http://127.0.0.1:8765 plugins.json
```

Linux 候选包中脚本在包根目录，使用 `python install_plugins.py ...`。兼容系统 Python 2.6+/3，仅标准库。相同 id 更新配置，原执行记录保留。

## 资源监测

正式版从 Linux `/proc` 读取 CPU、内存与进程，存储监测默认工作目录所在文件系统的可用空间。CPU 使用两次采样差值；首次没有历史时显示未知。进程 CPU 100% 表示一个逻辑核心，按 CPU 再按内存排序显示前 200 项；支持名称/PID 检索与仿真任务筛选。GPU 使用 `nvidia-smi`；无该工具、非 NVIDIA 或指标不受支持时显示未知，不显示虚构的 0%。

默认阈值 90%，可设 1–100%；监测页默认 5 秒、最低 3 秒刷新。其他可见页面每 15 秒检查提醒，隐藏页面停止轮询，不产生后台高频动画。关闭进程先展示 PID，提交时复核进程拥有者和启动标识，仅发送 SIGTERM；系统 PID 1、自身及父进程受保护。CentOS 6.9 没有 pidfd，标识复核与发信号之间仍存在极短的内核 PID 重用竞态，不将此机制当成特权安全边界。

Demo 的曲线、数值和任务均标为合成数据，关闭只移除演示记录，不向宿主进程发信号。

## 文件与波形分析

可导入或从项目打开 Virtuoso/Spectre、DC、Calibre、VCS 的文本日志、报告、网表、脚本。规则诊断与 AI 分析分开显示。可填写分析重点，AI 分析结果直接显示在当前文件下方，可复制；不会创建对话或跳转。最多向模型发送 120 KB 文本，并标明截断。离开页面后返回同一文件仍可看到本次结果；导入新文件不会错配之前的回答。Demo 是明确标记的离线规则分析，正式模式调用配置的内网模型。

CSV 波形第一列是时间，后续列是数值信号；时间非递减、数值有限。VCD 支持 scope、timescale、标量/向量/real、别名及 X/Z 保留。选择信号后用按钮或滚轮缩放，滑块平移。每次导入最多 2 MiB、64 信号、100,000 变化点（CSV 单列还受 50,000 行限制），达到限制标记不完整。宽于 53 位的 VCD 总线值保留原文本，数值图形为未知；不是全功能签核波形查看器。

PSF、FSDB、WLF、SHM、DDC 等专有二进制格式不提供原生解码，请先在厂商工具中导出 CSV/VCD 或文本。支持通用格式不代表商业 EDA 的所有版本已适配。

## Code 平台

需求与代码左右对照，支持 16 类：Verilog `.v`、SystemVerilog `.sv`、VHDL `.vhd`、Verilog-A `.va`、Verilog-AMS `.vams`、SPICE/HSPICE `.sp`、Spectre `.scs`、SKILL `.il`、OCEAN `.ocn`、Tcl `.tcl`、SDC `.sdc`、Python `.py`、MATLAB/Octave `.m`、Shell `.sh`、C `.c`、C++/SystemC 源码 `.cpp`。

切换语言保留本页各语言草稿；生成后可编辑和按对应扩展名下载。“另存为”只在保存动作时指定输出项目目录和相对路径，不覆盖已有文件。文件类型支持表示生成/编辑/导出入口支持，不表示其语法、功能或厂商方言已经通过验证。

每种语言可以单独配置“检查工具”，提供本机可执行文件绝对路径和参数 JSON，使用 `{file}` 传入私有暂存文件。建议用编译/语法检查模式，例如 Python `["-m","py_compile","{file}"]`、Bash `["-n","{file}"]`、Icarus `["-g2012","-tnull","{file}"]`。运行前展示命令，结果进入执行记录。工作台不自动安装编译器，也不默认执行生成脚本。旧设置中的 HDL 编译器仅作为三种旧 HDL 类型的兼容回退，不用于其他语言。

## 计算器

无需 AI 即可计算：四则运算、括号、幂 `^`（右结合）、取余 `%`、平方根/指数/对数/三角函数，以及变量定义。示例：变量 `R=1k`、`C=1n`，公式 `1/(2*pi*R*C)` 得到约 `159154.943092`。变量可引用其他变量，允许向前引用，循环定义会报错。

支持 rad/deg；`log`/`ln` 为自然对数，常用对数用 `log10`。工程后缀 `f p n u m k M meg G T` 区分大小写，`m=1e-3`、`M=meg=1e6`。常量 `pi`、`e`、`kB`、`qe`。热噪声、RC 截止频率和增益 dB 预设可直接修改。

独立解析器不使用 eval 或 shell，限制表达式长度、嵌套和变量数量。拒绝除零、非有限数值、函数定义域错误、未知函数/变量。使用双精度数值，不自动处理量纲，不做符号化求解方程或单位换算。各变量需先统一单位。

## EDA 控制

独立页面提供 MCP 连接清单、工具发现、参数说明、调用确认、执行记录和仿真任务状态。内置 Cadence 桥接复用既有 Virtuoso/OCEAN/Spectre 适配器；其他软件可配置 stdio 或 Streamable HTTP 服务，工具白名单由用户维护。完整接入步骤、GitHub 参考与目标环境限制见 [EDA_MCP.md](EDA_MCP.md)。

## 启动、保存与升级

配置在每次服务启动及每次保存后自动检查：加载全局环境脚本到独立进程，捕获环境供后续子进程继承；对配置的真实模型做一次短请求（可能消耗内网模型额度）。保存动作不需要重启服务。连续保存会排队验证最新配置。网页可见模型和环境是否成功或失败。

程序与数据分离。旧 Schema 升到 6 前原样保留元数据恢复文件，保留项目、文件备注、软件/插件配置、会话、批次、任务、实验与历史日志。请保留原数据目录及配置，安装升级无需删除任何数据。平台不再提供手动备份；工程目录继续使用公司备份方案。

服务器目标为 CentOS 6.9 x86_64；界面建议在现代浏览器通过 SSH 转发访问。目标机不需要 Node/Python 来运行工作台核心；只有可选批量插件脚本需要 Python。旧 CentOS 自带浏览器的 JavaScript/CSS 支持没有得到验证。
