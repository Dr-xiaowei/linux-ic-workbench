# IC Workbench 原生 Linux 客户端

0.8.0-rc3 候选，面向模拟 IC、数字 DE 和版图研发。正式客户端使用系统 Python/Tk 原生控件，网页仅用于独立 Demo。支持中文/English。公司 GLM、商业 EDA、GPU 和共享文件系统仍需现场验收；AI 生成和工具执行完成不等于设计通过验证。

## 安装、打开与升级

目标为 CentOS 6.9 x86_64，系统需要 Python 2.6+ 或 3、Tk 和可用的 X11/DISPLAY（例如公司 Linux 桌面或 VNC）。程序不捆绑 Go、模型、浏览器或 EDA 软件。

```sh
# 在解压后的安装包目录运行
sha256sum -c SHA256SUMS
./install.sh
~/.local/bin/ic-workbench --open
```

默认安装到 `~/.local/opt/ic-workbench`，终端命令为 `~/.local/bin/ic-workbench`。不需要 root；若需要安装系统 Tk，请联系管理员。无 DISPLAY 的纯 SSH 终端无法显示原生窗口。重复执行会聚焦本人已有窗口；关闭窗口会停止由其启动的后台。`--status` 查询本人实例，`--service` 单独启动本机 API。程序不会修改全局 `.cshrc`。

升级时解压新版本并再次执行 `./install.sh`。版本目录并存，程序数据在安装目录外，沿用本人数据目录即可；不要删数据目录来升级。相同版本不会覆盖安装。当前状态格式为 Schema 7；旧版本不能直接打开新版状态。工程文件由公司备份，平台不备份整个项目。

每个 Linux UID 使用独立配置、数据、端口和令牌。默认个人路径由启动时的 XDG 环境或 HOME 决定；使用 `--data /绝对/个人路径` 可明确指定。平台目录只允许本人访问，拒绝把多个账户指向同一数据库；不要使用共享 Linux 账号模拟多人隔离。公司 NFS/ACL 需要另行验收。

## AI、模板与代码审阅

在设置中配置内网 OpenAI 兼容 Chat Completions 完整地址和模型名。密钥放在启动进程的环境变量中（默认名 `ICW_MODEL_KEY`），不要写入工程或导入文件。是否支持 tools 须用公司模型实际验证；平台不会静默转用外网模型。

Linux Agent 默认关闭终端操作，可选本轮逐项确认或本轮自主执行。自主模式以本人 Linux 权限运行；选择目录不是操作系统沙箱。授权仅本轮有效。原始工具数据可以展开或在原生回执窗口查看；模型只输出工具 JSON 文本而未实际调用时，不能标为执行成功。

参数化任务模板位于 AI 对话：填入日志/CSV/脚本路径和目标，预览后再带入对话。内置模板只读，程序读取所选范围内指定 UTF-8 文件（最多 100 KB），附带路径和 SHA256。最多 12 参数、50 个人模板；预算 1～12 轮、10～600 秒。恢复普通对话后解除模板只读流程。

Code 支持 Verilog、SystemVerilog、VHDL、Verilog-A/AMS、SPICE、Spectre、SKILL、OCEAN、Tcl、SDC、Python、MATLAB、Shell、C、C++ 等。导入不改源文件；生成或修改先显示候选，采用后替换工作草稿，另存/导出才生成目标文件。编译/格式工具需要本人配置并安装。

“预览整份排版”处理全文件，“预览选中行”只处理选中的行；都是整理排版，不修复逻辑，采用前原草稿保留。AI 多文件修改集最多 8 个相对路径，原文及候选各合计 120 KB；逐文件审阅、采用、撤销，采用前检查内容哈希，不覆盖外部修改。它不是多文件事务，也不会自动 Git 提交。最多保留 20 组，移除审阅记录后不能再依靠该记录撤销，工程原件不随之删除。

## 文件、单位与工况

报告/网表支持 UTF-8 文本，波形支持 CSV/VCD。PSF、FSDB、WLF 等专有格式需要厂商工具先导出，不把未解析的二进制当作有效波形。

指标 CSV 必填 `metric,value,unit,corner,voltage,temperature,condition`，可选 `min,max`。电压填 V，温度填摄氏度数值；仅相同指标与完整工况匹配才比较，阈值取基线。兼容单位会换算，不兼容单位或不同工况标记不可比较；极值溢出、下溢、重复条件、非法文本拒绝。每份最多 256 KB、1000 行，dB 只算差值，不算百分比；结果不代表电路性能签核。

## 插件和 MCP

插件是本人允许执行的外部命令。手动添加需要名称、可执行文件、参数 JSON、工作目录与超时等信息。批量安装示例：

```sh
python install_plugins.py --help
# 按帮助填写平台实例/令牌和插件清单；导入配置本身不执行插件命令。
```

不同的软件自动化能力依赖实际 EDA 版本、许可和厂商脚本。Cadence 示例位于 `examples/cadence`，必须按公司项目修改与批准；协议接通不能替代实际仿真验收。详细配置见 [EDA 接入](EDA_ADAPTER.md)、[MCP 接入](EDA_MCP.md)、[平台 MCP](MCP.md)、[任务与代码检查](EDA_TASKS_AND_CODE_CHECKS.md)。

## 数据与问题排查

平台只保存项目路径、配置、会话/回执、审阅记录和工作草稿；草稿 gzip 压缩。主状态上限 64 MiB、未压缩工作草稿 12 MiB；保存失败会提示，不清空原数据。低磁盘空间、源文件改变和模型失败应按错误提示处理。重试写入中断的修改集会核对实际文件哈希，不应手动删除状态文件来“修复”。

`./acceptance-linux.sh` 可在隔离的临时目录验证后端启动和解析样例，不代表公司模型、EDA 或原生 GUI 全部通过。需要完整证据时查看源码项目的验证目录；客户端包不再附带历史截图、原始测试日志和开发工具。保留第三方许可证及必要操作说明，不删除产品功能来压缩包。
