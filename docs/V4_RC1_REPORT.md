## 未验证及原因

开发机为 macOS ARM64，无法访问公司目标环境。因此尚未验证 CentOS 6.9 实机运行、实际 NFS/断电/磁盘故障语义、Linux 全进程资源占用、GLM 5.3 的真实优化效果、商业 EDA 编译/仿真/综合/时序/模拟性能。静态构建、协议合同和界面通过不替代这些验收。

网页 Demo 的代码“优化”只做行末空白与换行整理，明确标识无逻辑优化；生产模式才请求配置的内网模型。导入上限 1 MiB、AI 输入上限 120 KB；超限返回错误，不静默截断。专有 PSF/FSDB 等仍需厂商导出。新版 GitHub 候选组件没有安装或验证旧系统运行兼容性。

平台快照包含偏好和工作草稿，不包含外部工程/运行产物、启动 config.json、外部环境脚本和密钥值；它们在原本地位置保留，完整备份需一并保存。回退旧版本必须使用独立恢复目录，不能把旧快照覆盖升级后数据。
