# 网页 Demo

运行 `python3 scripts/preview_demo.py`，打开输出的完整登录链接。仍使用隔离的 Demo 数据目录；重新构建不会清理历史记录。没有独立 Demo 安装包。

建议依次体验：

1. AI 对话将操作范围设为“项目”，选择 RC 项目，点击“整理项目”并发送，查看实际目录工具及执行进度。还可输入“搜索 gain”或“检查服务器资源”。这里是固定规则演示，不是真实 GLM。
2. 项目与文件打开 `results`、为文件添加备注，搜索 `gain`。项目可以手动添加多个路径。
3. 软件管理选择 Virtuoso 不同版本并启动，查看模拟执行记录；编辑软件可以逐行填写环境。
4. 插件查看安装说明，单独添加或批量导入 JSON；运行只生成演示回执。
5. 资源监测查看合成数据和任务、修改阈值、关闭一个演示任务（不影响宿主进程）。
6. 文件分析导入 CSV/VCD，或者从项目打开 `results/digital.vcd`，选择信号、缩放和平移。点击“让 AI 分析”后，离线规则结果就在当前页面显示。
7. Code 平台选择 Verilog-A、SPICE、SKILL、Python 等 16 种类型，查看对应固定示例，修改并导出正确格式。
8. 计算器直接计算 RC 截止频率、热噪声、增益；修改变量和公式，检查除零提示。
9. EDA 控制连接内置 MCP，发现工具，调用 list_projects 或 submit_simulation，查看回执及合成任务。
10. 设置保存并查看自动验证状态；Demo 不连接真实内网模型。

所有真实接入方式和限制见 [使用说明](V2_GUIDE.md)。页面左下角始终标有 WEB DEMO。
