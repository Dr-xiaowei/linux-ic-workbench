## 仍未完成的目标环境验收

当前主机为 macOS ARM64，无法访问公司 CentOS 6.9 x86_64、内网 GLM、GPU、商业 EDA、PDK/许可证及 HDL 编译器，因此以下事项不能认定通过：

1. CentOS 6.9 启动、目标机资源开销、实际共享服务器/NFS 权限与规模。
2. GLM 5.3 接口、工具调用兼容性、实际问答/诊断质量与研发提效。
3. Virtuoso/ADE、Spectre、VCS/DC/Calibre 等实际运行、图形环境、许可证及结果正确性。
4. NVIDIA 驱动对应的 GPU 指标、真实任务关闭、HDL 编译和仿真验证。
5. PSF/FSDB 等厂商专有数据的导出链路；当前只原生解析通用文本/CSV/VCD。

候选包提供目标机验收脚本、插件脚本和 [完整使用说明](V2_GUIDE.md)。旧 0.1.0-rc1 候选包和 [历史报告](V1_RC1_REPORT.md) 保留，旧证据不充当本次新增功能的验收证据。
