测试日志/代码示例均为自建且有明确预期的夹具；公式使用标准数值与独立预期值核对。不使用公司设计、PDK 或许可证资料。保持现有依赖，无新增浏览器框架或外部服务自动安装。

## 尚未验证

当前开发机是 macOS ARM64，无法访问公司 CentOS 6.9、GLM、商业 EDA、GPU、PDK/许可证或厂商编译器，因此以下仍待现场验收：

1. CentOS 6.9 x86_64 启动、NFS/权限、服务器实际资源占用；旧浏览器兼容性。建议现代浏览器经 SSH 转发访问。
2. GLM 5.3 的真实问答、代码生成、诊断质量和多轮工具规划；本地只验证接口行为与结果展示。
3. Virtuoso/Spectre 等商业软件执行与物理/电气结果，VCS/DC/Calibre/华大九天等专用 MCP 服务及版本适配；外部服务必须先在公司部署并单独验收。
4. 所有代码类型的真实编译/仿真/综合/时序签核；PSF/FSDB 等专有数据仍需厂商导出。
5. 真实 GPU 指标与进程关闭；可选 Node/Python MCP 桥接的系统最低要求与 CentOS 核心独立评估，不因平台静态构建就视为兼容。

Demo 的 AI 是离线规则/模板，EDA 是模拟引擎；协议成功不能替代真实 EDA 通过。使用方式见 [使用说明](V2_GUIDE.md)。旧候选包与历史证据保留。
