## 交付内容

| 要求 | 实现 |
| --- | --- |
| 取消平台项目备份 | 删除备份按钮与 Agent 创建动作，旧备份 API 返回错误，不再生成手动备份。项目只登记路径、备注、标签和配置，不复制工程；旧文件保留。格式升级仅保留元数据恢复文件。 |
| EDA 页 AI 任务对话 | 绑定选中的内置/外部 MCP 软件，模型只获得该连接允许的工具。原页显示规划、调用、服务端进度、后台任务状态和执行回执；支持取消、独立对话、草稿与最新进度恢复。 |
| 纳入研究第一项 IDEA-09 | 检查 → 根据日志限次 AI 修复 → 复检。1–3 次修复预算，实际检查日志和每轮结果可查看；工具失败、无效/不变候选或预算耗尽时停止。原文保留，候选审阅后采用。 |
| 纳入研究第二项 IDEA-10 | 按语言配置检查器和格式化器，诊断文件/行/列与点击定位，全文件/选中行格式化。按需运行，无新增常驻语言服务器或全文索引。 |

保持浅绿色、中文/English、原有十页分工和 Demo/生产数据隔离。IDEA-11 多文件/Git 修改集仍待判断；IDEA-12 增量备份按用户取消备份的决定不纳入。完整说明见 [EDA 与 Code 操作指南](EDA_TASKS_AND_CODE_CHECKS.md)、[本地数据说明](LOCAL_DATA_AND_CODE.md)。

## 未验证与接入限制

开发机为 macOS ARM64，无法访问公司环境，因此 **CentOS 6.9 实机、内网 GLM 5.3、商业 Virtuoso/Spectre/VCS、公司 MCP 适配器与许可证、实际 NFS/断电语义和 Linux 全进程负载尚未验证**。静态 ELF 和本机协议测试不替代这些验收。Verilator 本机未安装，本轮只验证其配置入口和诊断解析，没有声称真实执行。

EDA 控制需要软件对应的 MCP 服务或厂商桥接已经提供实际工具；添加名称/启动命令不会自动获得 EDA 控制能力。外部 MCP 未上报进度时仅显示实际调用阶段；请求取消不保证它已创建的后台作业终止，需要相应状态/取消工具。

Demo 仍离线：EDA 使用模拟桥接，代码检查只识别 `DEMO_ERROR` 演示标记，格式化仅整理空白。正式模式通过配置的内网模型和实际 CLI 执行；检查 PASS 只代表选定检查，不是芯片功能、性能或签核通过。完整 LSP/工程符号导航与多文件修改集未在本次实施。

历史版本结论保留在 [0.4 报告](V4_RC1_REPORT.md)；其中的备份功能和“建议尚未确认”属于历史状态，以本报告为准。
