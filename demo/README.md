# 网页 Demo

独立 Demo 安装包已按要求移除。Demo 继续使用独立网页界面，与正式原生 Linux 客户端共享业务和数据模型，通过本机服务预览，无需安装 Linux Demo 软件。

从项目根目录运行：

```sh
python3 scripts/preview_demo.py
```

打开终端打印的 `WEB_DEMO_URL` 完整地址，默认端口 18766。保持服务运行；Ctrl+C 停止。首次自动构建当前电脑适用的后台程序，需要本机 Go；以后源码未变会复用构建，不下载依赖。开发机启动脚本使用 Python 3，正式 Linux 原生客户端另需系统 Python 2.6+ / 3 与 Tk。

启动后自动载入演示工程。可以体验 AI 对话范围选择、纯项目文件管理、软件环境、文件内分析、Code 平台、计算器与 EDA MCP 控制，右上角可切换中英文。完整操作见 [Demo 操作说明](../docs/DEMO.md)。

- 服务仅本机可见，未发布到公网。
- AI 为明确标注的离线演示，EDA 使用解析 RC 模拟；不连接公司 GLM、商业 EDA 或生产配置。
- 数据单独保存在 `runtime-data/web-demo`，重启保留；不会清理之前的 Demo 或生产数据。
- 正式版不通过浏览器打开；网页 Demo 不代表原生窗口的像素布局。
- 生产候选仍在 `release/`，构建脚本不再生成 Demo 安装包。
